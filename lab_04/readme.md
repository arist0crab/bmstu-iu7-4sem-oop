# Лабораторная работа №2: "Контейнеры и классы"

Написать программу, эмулирующую работу лифта. К данной задаче необхдимо составить ДПС (диаграмма переходов состояний), на которую следует опираться при написании кода. Количество этажей в эмуляции не уточняется.

> [!IMPORTANT]
> Очевидно, для выполнения работы предполагается использование паттернов ООП. Однако, использование конкретного паттерна **состояние** не рекомендуется в крайней степени. В 2026 году все, кто решил использовать данный прием в реализации, были отправлены эту реализацию переделывать с нуля. Причины такой неприязни к конкретному паттерну остались за кадром.

## Дополнительные баллы

* два лифта
* на каждом этаже кнопки вверх и вниз
