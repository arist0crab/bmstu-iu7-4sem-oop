# Лабораторная работа №2: "Каркасный 3D viewer. ООП версия"

Создать каркасный 3D-viewer. Те же яйца, что и в первой лабораторной работе, но вид изподвыподверта.

Теперь для написания той же самой программы, которая выполняет те же самые действия с каркасными примитивами необходимо использовать методологию ООП, а именно паттерны проектирования. И это действительно сложная работа.
